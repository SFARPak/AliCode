# ROADMAP

This roadmap outlines the upcoming milestones for the Roo Code project, including target release versions and primary goals.

## Core Feature Completion (v3.49.0)

- Finalize the new CLI commands for project initialization and management.
- Complete the stub module implementation and integrate it with the extension UI.
- Add full branch creation utilities with Git integration.
- Ensure comprehensive test coverage for all new features.

## Stability & Performance (v3.50.0)

- Optimize context condensation and indexing performance.
- Harden native tool handling and race‑condition safeguards.
- Introduce automated performance benchmarks for the CLI.
- Resolve remaining edge‑case bugs from the 3.48.x series.

## Documentation & Release Preparation (v3.51.0)

- Publish updated developer documentation covering the re‑branding and new CLI.
- Add migration guides for existing Roo Code users.
- Prepare release notes and changelog automation.
- Conduct a thorough QA cycle with community testing.

## Public Release (v3.52.0)

- Release the stable version of Roo Code with the new branding.
- Distribute the VSIX package via the Marketplace.
- Launch the official website and marketing assets.
- Provide onboarding tutorials and sample projects.

## Future Enhancements (v3.53.0 and beyond)

- Expand provider support for emerging AI models.
- Introduce advanced workspace collaboration features.
- Add plug‑in architecture for third‑party extensions.
- Continue improving UI/UX based on user feedback.
